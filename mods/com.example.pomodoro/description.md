# Pomodoro

Twenty-five minutes of focus, five of rest. Click the Dock tile to start or pause.

- **Dock tile** with the time left, a progress ring and a badge for finished sessions.
- **Widget** for the board, with the same ring.
- **Command**: *Start or Pause Pomodoro* in the Command palette.
- **Hot corner**: put *Pomodoro* on any corner in Hot Corners.

A notification tells you when a session ends. That is the only permission it asks for.

It is also the reference plugin: every kind of registration in one short script. Read `main.js` to see how each one works.
