# Random Wallpaper Palette

One shortcut, a new mood. Each shuffle picks a hue, then three more a little further round the colour wheel, from deep shadow to bright crest, and applies them to:

- the live wallpaper's palette,
- the Dock and widget accents,
- Atelier's own accent.

Run **Random Wallpaper Palette** from the Command palette, or put **Random Palette** on a hot corner.

Not this time? **Revert** in Looks puts back everything from before the first change.
