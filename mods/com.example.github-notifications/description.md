# GitHub Notifications

Unread notifications from GitHub, on your desktop.

1. Run **Set GitHub Token** from the Command palette.
2. Paste a classic personal access token with the `notifications` scope. Make one at [github.com/settings/tokens](https://github.com/settings/tokens).
3. Add a **Plugin** widget to the board and choose *GitHub*.

The token is kept in the plugin's own storage and sent only to `api.github.com`, the one host it may reach. Clicking the Dock tile opens your notifications in the browser.

> Pull requests waiting for your review are drawn in orange.
